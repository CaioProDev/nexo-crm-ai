# Capturas reais do Nexo CRM

Esta pasta é reservada exclusivamente para screenshots reais do sistema em execução com os dados fictícios de `supabase/seed.sql`.

Arquivos esperados:

- `dashboard.png` — rota `/`
- `leads.png` — rota `/leads`
- `kanban.png` — rota `/funil`
- `ai-copilot.png` — painel de detalhes de um lead na rota `/leads`

Antes de capturar:

1. Configure `.env.local` e execute o schema e o seed demonstrativo.
2. Inicie a aplicação com `npm run dev`.
3. Confirme que a interface carregou os cinco leads fictícios.
4. Use uma janela com largura mínima de 1440 px e evite incluir credenciais, DevTools ou notificações do sistema.
5. Para `ai-copilot.png`, use somente uma análise realmente retornada pela API; não substitua o conteúdo por texto manual.

Não adicione placeholders, mockups ou respostas simuladas com esses nomes.
